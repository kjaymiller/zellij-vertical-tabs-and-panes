# Documentation

The docs follow the [Diátaxis](https://diataxis.fr/) framework, which divides documentation by user need:

| Section | Purpose | Read this when... |
|---------|---------|-------------------|
| [Tutorials](tutorials/) | Learning-oriented | You are new and want to be guided through a working setup |
| [How-to guides](how-to/) | Task-oriented | You know what you want and need a recipe |
| [Reference](reference/) | Information-oriented | You need to look up an option, variable, or message |
| [Explanation](explanation/) | Understanding-oriented | You want to know *why* the plugin works the way it does |
